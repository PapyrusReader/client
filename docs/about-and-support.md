# About and support

On phones, Settings opens a grouped index. Account, Appearance, Storage,
Accessibility, and About each open their own page. Desktop Settings retains its
sidebar. Settings navigation is immediate, including Back.

About → App updates opens a dedicated page with the installed version, latest
check result, automatic-check preference, and the action appropriate to the
installation channel. Fast retries preserve the previous result while checking,
and longer checks show progress without moving the action.

About reads the installed package version and build number. What's new opens the
matching `v<version>+<build>` release in `PapyrusReader/client`, using the release notes
generated by the release workflow. Development versions without a published tag
do not have release notes yet. Licenses are bundled with the app and work offline.
About prepares the license list before opening it to avoid a blank first frame.
Direct license routes retain delayed loading feedback and retry on failure.

Support submits a bug report or feature request to the selected Papyrus server.
No GitHub account is required. Its text, attachments, and app
version/platform become a public client-repository issue. The server must enable
`SUPPORT_GITHUB_TOKEN`, as documented in the [server support guide](https://github.com/PapyrusReader/server/blob/development/docs/support.md). Failed submissions
keep the current form text and selected files, and uncertain submissions are not retried automatically.

Attach up to five images or videos, 10 MB per file. PNG, JPEG, GIF, WebP, MP4, MOV,
and WebM are supported. Files can be removed before submission and upload only
when Submit is pressed. Images and videos are embedded in the GitHub issue.

The Support form follows Appearance → Page alignment (Left or Center). Changing
alignment preserves the draft and selected attachments.
